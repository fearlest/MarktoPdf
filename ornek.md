# Proje Durum Raporu

Bu belge **MarkToPdf** komut satırı aracı ile C# üzerinden otomatik üretilmiştir.

## Tamamlanan Modüller
* Markdown ayrıştırıcı servisi
* HTML & CSS entegrasyonu
* Chromium tabanlı PDF motoru

## Sistem Özeti
| Modül | Durum | Teknoloji |
| :--- | :--- | :--- |
| Markdown Parser | Tamamlandı | Markdig |
| PDF Engine | Tamamlandı | PuppeteerSharp |
